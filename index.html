Kenali bagian-bagian Python

Program adalah serangkaian instruksi. Python membantu kita menuliskan instruksi itu dengan sintaks yang ringkas dan mudah dibaca.

x=

Variabel

Tempat menyimpan data supaya bisa dipakai lagi. Contoh: nama = "Dina".

Aa

Tipe data

Data punya bentuk berbeda: teks (str), bilangan bulat (int), dan benar atau salah (bool).

()

Fungsi

Instruksi yang bisa digunakan kembali. print() menampilkan sesuatu ke layar.

if

Kondisi

if dan else membuat program memilih tindakan berdasarkan suatu syarat.

↻

Contoh sederhana

Menghitung total belanja

Contoh ini menggabungkan variabel, angka, dan fungsi untuk menampilkan hasil.

belanja.pyPython 3
harga_roti = 12000
harga_susu = 18000
jumlah = harga_roti + harga_susu

print(f"Total belanja: Rp{jumlah}")
1. Simpan nilai

Harga masing-masing barang dimasukkan ke variabel.

2. Hitung

Tanda + menjumlahkan kedua nilai harga.

3. Tampilkan

print() menampilkan total, yaitu Rp30000.
